# O'qituvchi Sidebar Navigatsiyasini Yaxshilash Rejasi

## Maqsad
O'qituvchi uchun sidebar navigatsiyasiga quyidagi bo'limlarni qo'shish:
1. Guruhlar ro'yxati
2. Xabarlar
3. Dars jadvali
4. Baholar (already exists)
5. Profil

## Hozirgi Holat
- Sidebar'da faqat 3 ta bog'lanish bor: Dashboard, Guruhlar, Baholar
- `GroupListView` faqat adminlar uchun (AdminRequiredMixin)
- Xabarlar, jadval, profil uchun maxsus sahifalar yo'q

## Reja

### 1. Guruhlar Ro'yxati (O'qituvchilar uchun)
**Fayl:** `groups_app/views.py`
- Yangi `TeacherGroupListView` yaratish
- Faqat o'qituvchining guruhlarini ko'rsatish
- `TeacherRequiredMixin` ishlatish

**Fayl:** `groups_app/urls.py`
- Yangi URL qo'shish: `teacher/groups/`

**Fayl:** `templates/groups_app/teacher_group_list.html`
- Yangi shablon yaratish
- Mobil moslashuvchan dizayn

### 2. Xabarlar (O'qituvchilar uchun)
**Fayl:** `users1/views.py`
- Yangi `TeacherMessagesView` yaratish
- TelegramAppeal modellasidan foydalanish
- Faqat o'qituvchi guruhidagi xabarlarni ko'rsatish

**Fayl:** `users1/urls.py`
- Yangi URL qo'shish: `teacher/messages/`

**Fayl:** `templates/users1/teacher_messages.html`
- Yangi shablon yaratish
- Xabarlarni javob berish funksiyasi

### 3. Dars Jadvali (O'qituvchilar uchun)
**Fayl:** `users1/views.py`
- Yangi `TeacherScheduleView` yaratish
- Guruhlar dars kunlari va vaqtlarini ko'rsatish

**Fayl:** `users1/urls.py`
- Yangi URL qo'shish: `teacher/schedule/`

**Fayl:** `templates/users1/teacher_schedule.html`
- Yangi shablon yaratish
- Haftalik jadval ko'rinishi

### 4. Profil (O'qituvchilar uchun)
**Fayl:** `users1/views.py`
- Yangi `TeacherProfileView` yaratish
- Foydalanuvchi ma'lumotlarini ko'rsatish va tahrirlash

**Fayl:** `users1/urls.py`
- Yangi URL qo'shish: `teacher/profile/`

**Fayl:** `templates/users1/teacher_profile.html`
- Yangi shablon yaratish
- Profil ma'lumotlarini tahrirlash formasi

### 5. Sidebar Navigatsiyasini Yangilash
**Fayl:** `templates/base.html`
- O'qituvchilar uchun yangi navigatsiya havolalarini qo'shish:
  - Dashboard
  - Guruhlar ro'yxati
  - Xabarlar
  - Dars jadvali
  - Baholar
  - Profil
- Pastki navigatsiyani yangilash (mobil uchun)

## Fayllar Ro'yxati
1. `groups_app/views.py` - TeacherGroupListView qo'shish
2. `groups_app/urls.py` - teacher/groups/ URL qo'shish
3. `templates/groups_app/teacher_group_list.html` - yangi shablon
4. `users1/views.py` - TeacherMessagesView, TeacherScheduleView, TeacherProfileView qo'shish
5. `users1/urls.py` - teacher/messages/, teacher/schedule/, teacher/profile/ URL lar qo'shish
6. `templates/users1/teacher_messages.html` - yangi shablon
7. `templates/users1/teacher_schedule.html` - yangi shablon
8. `templates/users1/teacher_profile.html` - yangi shablon
9. `templates/base.html` - sidebar navigatsiyasini yangilash

## Tekshirish
1. Django serverni ishga tushirish
2. O'qituvchi sifatida kirish
3. Har bir navigatsiya havolasini bosish
4. Mobil qurilmada tekshirish
5. Barcha sahifalar to'g'ri yuklanishini tekshirish
