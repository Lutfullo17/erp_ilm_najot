# Xonalar Bandligi Jadvali — Kamchiliklarni tuzatish

## Muammolar (4 ta)

1. **Modal overlay ustidan chiqmoqda** — yangi oyna (window) ochilishi kerak
2. **O'tgan kunlarni tanlash mumkin** — ular umuman ko'rinasmasin, tanlab bo'lmasin
3. **Vaqt AM/PM formatda** — 24 soatlik format bo'lishi kerak
4. **Konflikt tekshiruvi** — boshqa o'qituvchilar va guruhlar bilan xona/vaqt to'qnashuvini to'liq tekshirish kerak

---

## Tuzatishlar

### 1. Yangi oyna ochish (modal emas)
**Fayl:** `templates/groups_app/room_availability.html`

- Modal overlay butunlay o'chiriladi
- "O'zgartirish" tugmasi bosilganda `window.open()` bilan yangi oyna ochiladi
- Yangi oynada to'liq shakl: kun tanlash, xona, vaqt, sabab
- Saqlaganda yoki yopganda avtomatik yangilanadi

URL: `GET /groups/<pk>/edit-lesson/<day>/` — form ko'rinishida (GET)
URL: `POST /groups/<pk>/edit-lesson/<day>/` — saqlash

### 2. O'tgan kunlarni yashirish
**Fayl:** `templates/groups_app/room_availability.html`

JavaScript `renderDayButtons()` funksiyasida:
- O'tgan kunlarni (bugundan oldingi) umuman render qilmaslik
- Faqat bugun + kelajakdagi kunlar + "O'zgartirmaslik" tugmasi

### 3. Vaqt 24 soatlik format
**Fayl:** `templates/groups_app/room_availability.html`

- `<input type="time">` — bu allaqachon 24 soatlik formatda ishlaydi
- Lekin ba'zi brauzerlarda AM/PM ko'rsatishi mumkin
- Yechim: qo'shimcha JavaScript validate bilan `HH:MM` formatni tekshirish
- Frontend validation: `pattern="[01]\\d|2[0-3]):[0-5]\\d"`

### 4. Konflikt tekshiruvini kuchaytirish
**Fayl:** `users1/services.py`

`validate_schedule_change()` funksiyasiga qo'shimcha:
- Xona konflikti: boshqa guruh shu xonada shu kunda bandmikan (mavjud)
- O'qituvchi konflikti: boshqa guruhda shu o'qituvchi dars beradimi (mavjud)
- **Qo'shimcha:** Guruh nomi bo'yicha ham tekshirish (bir xil nomdagi guruhlar)
- Xabarlar aniqroq bo'lishi kerak

## Tekshirish

1. Yangi oyna ochilishi va to'liq ishlashi
2. O'tgan kunlar tanlab bo'lmasligi
