# To'lovni Qabul Qilish — Yangi Interfeys Rejasi

## Maqsad
To'lov qabul qilish formasini qayta dizayn qilish: qidiruv → o'quvchi topish → qarz miqdorini ko'rish → 3 ta tugma (To'liq/Qisman/Ko'proq) orqali to'lov.

## Talablar
1. **Qidiruv** — ism yoki telefon bo'yicha o'quvchini qidirish
2. **O'quvchi topilgandan keyin** — guruhdagi qarz miqdorini ko'rsatish
3. **3 ta tugma**:
   - **To'liq** — to'liq qarzni to'lash (avtomatik summa)
   - **Qisman** — summa kiritish maydoni ochiladi
   - **Ko'proq** — qarzdan ortiq summa kiritish maydoni ochiladi
4. **To'lov sanasi** — default "Bugun", "Boshqa kun" tugma bilan sanani o'zgartirish
5. **Izoh kerak emas** — olib tashlash

## O'zgartiriladigan fayllar

### 1. `templates/payments/payment_form.html` — To'liq qayta yozish
- **Qidiruv qismi**: input + results list (API orqali)
- **O'quvchi topilgandan keyin**: student balance API dan qarz ma'lumotini olish
- **3 ta tugma**: To'liq, Qisman, Ko'proq
- **Sana**: "Bugun" (default) va "Boshqa kun" toggle
- **Izoh** olib tashlandi

### 2. `payments/views.py` — Yangi API endpoint
- `api_search_students` — qidiruv API (ism/telefon bo'yicha)
- Mavjud `student_balance` API qayta ishlatiladi

### 3. `payments/urls.py` — Yangi URL qo'shish
- `api/search/` — qidiruv endpoint

## Implementation Details

### Qidiruv API (`api_search_students`)
- GET `?q=<query>` — ism yoki telefon bo'yicha barcha o'quvchilarni qidirish
- Natija: `[{id, full_name, phone, groups: [{id, name, monthly_fee}]}]`
- O'quvchi bir nechta guruhda bo'lsa, barcha guruhlar ro'yxati qaytariladi
- Foydalanuvchi guruhni tanlaydi → shu guruhdagi qarz ko'rsatiladi

### Frontend Flow
1. Qidiruv input → typing debounce (300ms) → API call
2. Natijalar ro'yxati ko'rinadi → o'quvchi tanlash
3. O'quvchi tanlangandan keyin:
   - Agar 1 ta guruhda bo'lsa → avtomatik tanlash
   - Agar bir nechta guruhda bo'lsa → guruh tanlash tugmalari chiqadi
4. Guruh tanlangandan keyin:
   - Student balance API chaqiriladi
   - Jami qarz miqdori ko'rsatiladi
   - 3 ta tugma chiqadi (To'liq/Qisman/Ko'proq)
5. "To'liq" → summa = jami qarz
6. "Qisman" → summa input ochiladi (0 dan qarzgacha)
7. "Ko'proq" → summa input ochiladi (qarzdan ortiq)
8. "Bugun" tugmasi → boshqa kun inputi ochiladi
9. "Saqlash" → to'lov API chaqiriladi
