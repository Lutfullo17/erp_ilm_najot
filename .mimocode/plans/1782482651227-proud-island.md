# Guruh qo'shish formasi xatosini tuzatish

## Muammo
Yangi guruh qo'shishda "oylik to'lov" maydonini to'ldirganda "raqam kiriting" xatosi chiqadi. Aslida muammo `start_date` maydonida — ikki ta input bir xil `name="start_date"` atributiga ega.

## Sabab
`groups_app/group_form.html` faylida:
- Ko'rinadigan sana inputi: `name="start_date"` (DD.MM.YYYY)
- Yashirin sana inputi: `name="start_date"` (YYYY-MM-DD)

Form yuborilganda Django ikkita qiymat qabul qiladi → validatsiya xatosi.

## Tuzatish
**Fayl:** `templates/groups_app/group_form.html`

Ko'rinadigan sana inputidan `name` atributini o'chirish kerak (41-qator):
```html
<!-- OLD -->
<input type="text" id="id_start_date" name="start_date" ...>

<!-- YANGI -->
<input type="text" id="id_start_date" ...>
```

Yashirin input `name="start_date"` bilan qoladi — serverga shu yuboriladi.

## Tekshirish
1. Guruh qo'shish sahifasiga o'tish
2. Barcha maydonlarni to'ldirish (shu jumladan oylik to'lov)
3. Saqlash tugmasini bosish
4. Guruh muvaffaqiyatli qo'shilishi kerak
