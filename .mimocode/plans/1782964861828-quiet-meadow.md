# Baholash tizimi yangiliklari

## 1. Baho qulflash — bir marta qo'yilgan baho o'zgartirib bo'lmaydigan qilish

**Muammo**: Hozir `save_grades()` har saqlashda `get_or_create` + update qiladi, ya'ni baho qayta yoziladi.

**Yechim**: `grades/services.py` — `save_grades()` funksiyasiga tekshirish qo'shish: agar `GradeRecord` allaqachon mavjud bo'lsa, `GradeInputError` xatosini qaytarsin.

**O'zgartiriladigan fayl**: `grades/services.py:191-200`

```python
# Hozir:
record, _ = GradeRecord.objects.get_or_create(...)
record.percentage = data['percentage']  # doim update
record.save()

# Yangi:
record, created = GradeRecord.objects.get_or_create(...)
if not created:
    raise GradeInputError(f"{student} uchun baho allaqachon qo'yilgan. O'zgartirib bo'lmaydi.")
record.percentage = data['percentage']
record.save()
```

Shablon (`grades/grade_input.html`) ga ham qulflangan o'quvchilarni ko'rsatish kerak:
- Agar baho allaqachon qo'yilgan bo'lsa, input `readonly` + yashil rama + "Qulflangan" badge ko'rsatilsin
- Saqlash tugmasi faqat hali baho qo'ymagan o'quvchilar uchun ishlasin

Buning uchun `get_grade_snapshot()` ga `is_locked` maydonini qo'shish kerak.

## 2. Bot xabari — faqat yangi baho qo'yilganda yuborilsin

**Hozirgi holat**: `grades/signals.py` — `notify_grade_added` faqat `created=True` da ishlaydi. Bu to'g'ri.

**Qo'shimcha**: `grades/services.py:notify_parent_of_grades()` ham mavjud — bu ham xabar yuboradi. Ikkita xabar ketmasligi kerak. Signal orqali yuborilsin, `notify_parent_of_grades()` chaqirilmasin.

**O'zgartiriladigan fayl**: `grades/services.py:205` — `notify_parent_of_grades()` chaqiruvini o'chirish (signal yetarli).

## 3. Dars jadvalida "Imtihon" belgilash

**Maqsad**: Har oyda 1 marta imtihon bo'lishi kerak, jadvalda "Imtihon" deb belgilansin.

**Yechim**: `attendance/models.py` — `LessonPlan` modeliga `is_exam` boolean qo'shish.

**O'zgartiriladigan fayllar**:
- `attendance/models.py` — `LessonPlan` ga `is_exam = models.BooleanField(default=False)` qo'shish
- `users1/views.py` — `TeacherScheduleView.get_context_data` ga `is_exam` ni contextga qo'shish
- `templates/users1/teacher_schedule.html` — "Imtihon" belgisi + checkbox/toggle qo'shish
- Migration yaratish

**Shablon o'zgarishi**: Har bir dars qatoriga checkbox qo'shilsin: "Imtihon". Toggle qilinganda `is_exam` yangilansin.
